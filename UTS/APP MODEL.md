# Aplikasi Model Tutupan Lahan (Streamlit)

Aplikasi web interaktif ini dibangun menggunakan **Streamlit** untuk mendemonstrasikan implementasi model *machine learning* dalam klasifikasi dan pemetaan tutupan lahan (*Land Use / Land Cover*) di wilayah Jawa Timur. 

Melalui antarmuka web ini, pengguna dapat melihat visualisasi sebaran lahan, menguji prediksi kelas tutupan lahan (Bangunan, Sawah, Perairan, Hutan Biasa, dan Hutan Mangrove) secara *real-time*, serta mengeksplorasi hasil pemodelan citra satelit Sentinel-2A.
